# การสำรองและกู้คืนข้อมูล

| เป้าหมาย | ค่าเสนอ (ผู้อำนวยการอนุมัติ) |
|---|---|
| RPO ข้อมูลสูญหายได้ไม่เกิน | 24 ชั่วโมง |
| RTO กลับมาใช้งานได้ภายใน | 1 วันทำการ |
| เจ้าของกระบวนการ | ผู้ดูแลระบบ [ชื่อ] |

## สิ่งที่ต้องสำรอง

| ข้อมูล | วิธี | ความถี่ |
|---|---|---|
| ไฟล์ Sheets หลัก | `backupWorkbook` (trigger 01:00–02:00) ทำสำเนา `SmartLTC Backup yyyy-MM-dd` ในโฟลเดอร์ `backups` เก็บ 35 วัน ผลอยู่ในชีต `JobRuns` (`WORKBOOK_BACKUP`) | ทุกวัน อัตโนมัติ |
| ภาพถ่าย/ลายมือชื่อ/รูปบุคลากร | อยู่ในโฟลเดอร์ Drive ของบัญชีหน่วยงาน ไฟล์ที่ลบไปอยู่ในถังขยะ 30 วัน | — |
| สำเนานอกบัญชี Google | ดาวน์โหลด backup ล่าสุดเป็น `.xlsx` เข้ารหัสด้วย 7-Zip (AES-256) เก็บใน external drive ที่ล็อกไว้ หรือคลาวด์ของหน่วยงานอื่น | ทุกเดือน (ด้วยมือ) |
| กุญแจ | password manager/ที่เก็บเข้ารหัส (ดู `ACCESS_POLICY.md`) | ทุกครั้งที่สร้าง/หมุน |
| D1 (session, TOTP, security events) | ไม่ต้องสำรอง: กู้ได้โดยให้ผู้ใช้ผูกแอปใหม่ เก็บเฉพาะ `security_events` เป็นหลักฐานด้วย `wrangler d1 export` ทุกเดือน | ทุกเดือน |
| โค้ด | GitHub repository | ทุก commit |

สำเนา backup มีข้อมูลสุขภาพเหมือนไฟล์จริง (เลขบัตรประชาชนยังเข้ารหัสอยู่) ต้องคุ้มครองระดับเดียวกัน

## ตรวจทุกสัปดาห์

- ชีต `JobRuns` มี `WORKBOOK_BACKUP` สถานะ `SUCCESS` ครบทุกวัน
- โฟลเดอร์ `backups` มีไฟล์ล่าสุดของเมื่อวาน

## กู้คืน

### กรณีข้อมูลบางส่วนผิด/ถูกลบ

1. เปิด backup ของวันก่อนเกิดเหตุ
2. คัดลอกเฉพาะแถวที่ต้องการกลับไปชีตจริง โดยคงหัวคอลัมน์และ `recordVersion`
3. บันทึกในแบบบันทึกเหตุว่ากู้อะไร จาก backup วันไหน

### กรณีไฟล์หลักเสียทั้งไฟล์

1. หยุดการบันทึก: แจ้งผู้ใช้ หรือหยุดระบบชั่วคราว (`INCIDENT_RESPONSE.md` ข้อ 1)
2. ทำสำเนาไฟล์ backup ล่าสุดออกมาเป็นไฟล์ใหม่ `Smart LTC PILOT (restored yyyy-MM-dd)`
3. ตั้ง Script Property `SPREADSHEET_ID` เป็น ID ของไฟล์ใหม่
4. รัน `initializePilotWorkbook` (เพิ่มเฉพาะชีตที่ขาด ไม่ลบข้อมูล)
5. เข้าสู่ระบบด้วยบัญชี CM ทดสอบ ตรวจรายชื่อผู้รับบริการและงานเยี่ยมล่าสุด
6. แจ้งผู้ใช้ให้บันทึกการเยี่ยมที่ทำหลังเวลาของ backup ซ้ำ

### กรณีบัญชี Cloudflare หรือ Worker ใช้ไม่ได้

สร้าง Worker/D1/KV ใหม่ตาม `docs/DEPLOYMENT.md` ใส่ secrets จากที่เก็บกุญแจ (ค่าเดิม) แล้ว deploy ผู้ใช้ทุกคนผูกแอปใหม่ ข้อมูลใน Sheets ไม่กระทบ

## ซ้อมกู้คืน

ก่อนนำข้อมูลจริงเข้า และทุก 6 เดือน: กู้ backup ลงไฟล์ใหม่ ชี้ระบบไปไฟล์นั้นชั่วคราว (หรือเปิดดูในระบบทดสอบ) ตรวจว่าข้อมูลครบและอ่านเลขบัตร 4 หลักท้ายได้ จับเวลาแล้วบันทึกผล
