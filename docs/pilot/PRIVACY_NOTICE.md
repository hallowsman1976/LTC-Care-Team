# ประกาศความเป็นส่วนตัว — ระบบดูแลผู้สูงอายุที่มีภาวะพึ่งพิง (Smart LTC Care)

> **ร่างสำหรับให้ DPO/ฝ่ายกฎหมายตรวจ** · เวอร์ชัน `2026-10-v1` (ต้องตรงกับ `VITE_PRIVACY_NOTICE_VERSION`)
> ข้อความใน [วงเล็บเหลี่ยม] ต้องกรอกโดยหน่วยงาน ร่างนี้ไม่ใช่ความเห็นทางกฎหมาย

[ชื่อหน่วยบริการ] ("หน่วยบริการ") เก็บและใช้ข้อมูลส่วนบุคคลของผู้รับบริการในโครงการดูแลระยะยาวด้านสาธารณสุขสำหรับผู้สูงอายุที่มีภาวะพึ่งพิง (LTC) ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ประกาศนี้อธิบายว่าเก็บข้อมูลอะไร เพื่ออะไร เก็บนานเท่าใด และท่านมีสิทธิอะไรบ้าง

## 1. ผู้ควบคุมข้อมูลและช่องทางติดต่อ

- ผู้ควบคุมข้อมูลส่วนบุคคล: [ชื่อหน่วยบริการ] ที่อยู่ [ที่อยู่] โทร [เบอร์]
- เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) หรือผู้ประสานงาน: [ชื่อ/ตำแหน่ง] อีเมล [อีเมล] โทร [เบอร์]

## 2. ข้อมูลที่เก็บ

| กลุ่มข้อมูล | ตัวอย่าง |
|---|---|
| ข้อมูลระบุตัวตน | ชื่อ-สกุล วันเกิด เพศ เลขประจำตัวประชาชน HN |
| ข้อมูลติดต่อ | ที่อยู่ หมู่บ้าน พิกัดบ้าน เบอร์โทร |
| ผู้ดูแลหลักในครอบครัว | ชื่อ ความสัมพันธ์ เบอร์โทร |
| สิทธิการรักษา | ประเภทสิทธิ |
| **ข้อมูลสุขภาพ (ข้อมูลอ่อนไหว)** | โรคประจำตัว คะแนน ADL กลุ่มผู้มีภาวะพึ่งพิง แผนการดูแล บันทึกการเยี่ยมบ้าน สัญญาณชีพ ภาวะสุขภาพจิต |
| ภาพและลายมือชื่อ | ภาพผู้รับบริการและกิจกรรมการดูแลระหว่างเยี่ยมบ้าน ลายมือชื่อรับรองการเยี่ยม |

## 3. วัตถุประสงค์และฐานทางกฎหมาย

| วัตถุประสงค์ | ฐานทางกฎหมาย (ให้ DPO ยืนยัน) |
|---|---|
| ประเมินภาวะพึ่งพิง จัดทำและติดตามแผนการดูแลรายบุคคล | ม.26(5)(ก) เวชศาสตร์ป้องกัน การวินิจฉัยโรค การให้บริการด้านสุขภาพหรือสังคม; ม.24(4) ภารกิจเพื่อประโยชน์สาธารณะ |
| มอบหมายและบันทึกการเยี่ยมบ้านของผู้ดูแล (CG) | ม.26(5)(ก) และ ม.24(4) |
| รายงานผลและเบิกจ่ายตามระบบ LTC ของ สปสช. และหน่วยงานที่เกี่ยวข้อง | ม.26(5)(ข) ประโยชน์สาธารณะด้านการสาธารณสุข; ม.24(6) หน้าที่ตามกฎหมาย |
| ภาพถ่ายและลายมือชื่อในการเยี่ยมบ้าน | ความยินยอมโดยชัดแจ้ง ม.26 วรรคหนึ่ง (ขอแยกจากการรับบริการ ปฏิเสธได้โดยไม่กระทบการดูแล) |
| ตรวจสอบย้อนหลังและป้องกันการเข้าถึงโดยมิชอบ | ม.24(5) ประโยชน์โดยชอบด้วยกฎหมาย |

## 4. ผู้ที่เข้าถึงข้อมูล

- ผู้จัดการการดูแล (CM) ของหน่วยบริการ: เข้าถึงข้อมูลผู้รับบริการในความรับผิดชอบ
- ผู้ดูแล (CG): เห็นเฉพาะผู้รับบริการที่ได้รับมอบหมาย
- หน่วยงานที่กฎหมายกำหนดหรือเกี่ยวข้องกับการเบิกจ่าย เช่น สปสช. องค์กรปกครองส่วนท้องถิ่นที่บริหารกองทุน LTC [ระบุ]
- ผู้ให้บริการระบบ: Google LLC (จัดเก็บไฟล์ Google Sheets/Drive) และ Cloudflare, Inc. (เครือข่ายและระบบเข้าสู่ระบบ) ซึ่งอาจประมวลผลข้อมูลนอกประเทศไทย หน่วยบริการใช้ข้อกำหนดของผู้ให้บริการเป็นมาตรการคุ้มครองตาม ม.28–29 [DPO ตรวจและระบุ]

หน่วยบริการไม่ขายข้อมูล และไม่ใช้ข้อมูลเพื่อการตลาด

## 5. ระยะเวลาเก็บ

เก็บตลอดระยะเวลาที่รับบริการ และต่อไปอีก [5] ปีหลังยุติบริการ เพื่อการตรวจสอบและเบิกจ่าย แล้วลบหรือทำให้ไม่สามารถระบุตัวตนได้ รายละเอียดอยู่ใน `RETENTION_SCHEDULE.md`

## 6. การรักษาความปลอดภัย

- เลขประจำตัวประชาชนถูกเข้ารหัสก่อนบันทึก และแสดงในระบบเพียง 4 หลักท้าย
- ผู้ใช้ทุกคนเข้าสู่ระบบด้วยรหัสผ่านและรหัสยืนยันจากแอปในโทรศัพท์ (ยืนยันตัวตนสองชั้น)
- ผู้ดูแลเห็นเฉพาะผู้รับบริการที่ได้รับมอบหมาย และการเข้าถึงและแก้ไขทุกครั้งถูกบันทึก
- ไฟล์ข้อมูลไม่เปิดแชร์สาธารณะ และสำรองข้อมูลทุกวัน

## 7. สิทธิของเจ้าของข้อมูล

ท่านหรือผู้แทนโดยชอบธรรมมีสิทธิ ขอเข้าถึงและขอสำเนา ขอแก้ไขให้ถูกต้อง ขอให้ลบหรือระงับการใช้ (เท่าที่ไม่ขัดกับหน้าที่ตามกฎหมาย) คัดค้านการประมวลผล ถอนความยินยอมเรื่องภาพถ่ายและลายมือชื่อ และร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.)

ยื่นคำขอได้ที่ [ช่องทาง] หน่วยบริการจะตอบภายใน 30 วัน

## 8. การเปลี่ยนแปลงประกาศ

เมื่อแก้ไขประกาศ หน่วยบริการจะเปลี่ยนเลขเวอร์ชันและแจ้งผู้รับบริการในการเยี่ยมครั้งถัดไป ระบบบันทึกเวอร์ชันที่ใช้ตอนลงทะเบียนผู้รับบริการแต่ละราย
