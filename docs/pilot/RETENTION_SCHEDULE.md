# บันทึกกิจกรรมการประมวลผลและระยะเวลาเก็บข้อมูล

> ร่างสำหรับ DPO · ระยะเวลาใน [วงเล็บ] เป็นค่าเสนอ ต้องยืนยันกับระเบียบของหน่วยงานต้นสังกัดและข้อกำหนดการเบิกจ่ายกองทุน LTC

## บันทึกกิจกรรมการประมวลผล (ROPA) โดยย่อ — มาตรา 39

| รายการ | รายละเอียด |
|---|---|
| ผู้ควบคุมข้อมูล | [ชื่อหน่วยบริการ] |
| กิจกรรม | บริหารการดูแลระยะยาวด้านสาธารณสุขสำหรับผู้มีภาวะพึ่งพิง |
| เจ้าของข้อมูล | ผู้รับบริการ ผู้ดูแลในครอบครัว บุคลากร CM/CG |
| ฐานทางกฎหมาย | ดู `PRIVACY_NOTICE.md` ข้อ 3 |
| ที่เก็บ | Google Sheets/Drive ของบัญชีหน่วยงาน · Cloudflare D1/KV (session, รหัสยืนยันตัวตนที่เข้ารหัส, บันทึกความปลอดภัย) |
| ผู้ประมวลผล | Google LLC, Cloudflare, Inc. |
| โอนต่างประเทศ | เป็นไปได้ (ศูนย์ข้อมูลของผู้ให้บริการ) — DPO ระบุมาตรการ |
| มาตรการความปลอดภัย | `docs/SECURITY.md`, `ACCESS_POLICY.md` |

## ระยะเวลาเก็บ

| ข้อมูล (ชีต/ที่เก็บ) | ระยะเวลา | เมื่อครบกำหนด | ผู้รับผิดชอบ |
|---|---|---|---|
| ผู้รับบริการ ช่วงการดูแล แผนการดูแล ADL การเยี่ยม (`Patients`, `CareEpisodes`, `CarePlans*`, `ADLAssessments`, `LTCClassifications`, `Visit*`, `Visit_Records`) | ระหว่างรับบริการ + [5] ปีหลังยุติบริการ | ลบแถวหรือแทนชื่อ/ที่อยู่/เลขบัตรด้วยรหัส | CM lead |
| ภาพถ่ายและลายมือชื่อ (โฟลเดอร์รูปภาพ, `VisitImages`) | [2] ปีหลังวันเยี่ยม หรือเมื่อถอนความยินยอม | ลบไฟล์ใน Drive และล้างถังขยะ | CM lead |
| ความยินยอม (`PatientConsents`) | เท่ากับข้อมูลที่อ้างถึง + [1] ปี | ลบ | DPO |
| บัญชีบุคลากร (`Users`, `StaffProfiles`, `CaregiverProfiles`) | ระหว่างปฏิบัติงาน + [2] ปีหลังพ้นหน้าที่ (ปิดใช้งานทันทีที่พ้นหน้าที่) | ลบรูปและเลขบัตร คงชื่อเพื่อการตรวจสอบย้อนหลัง | ผู้ดูแลระบบ |
| รหัสผ่าน (`AuthCredentials`) | ใช้งานอยู่: ตลอด · ที่ถูกแทนที่: [90] วัน | ลบแถว `REVOKED` | ผู้ดูแลระบบ |
| บันทึกการตรวจสอบ (`AuditLogs` + ไฟล์ archive รายเดือน) | [5] ปี | ลบไฟล์ archive เดือนที่ครบกำหนด | DPO |
| Session (D1 `sessions`) | 8 ชั่วโมง (หมดอายุอัตโนมัติ) · ลบแถวเก่าทุก [3] เดือน | `DELETE FROM sessions WHERE created_at < …` | ผู้ดูแลระบบ |
| บันทึกความปลอดภัย (D1 `security_events`) | [2] ปี | ลบแถวเก่า | ผู้ดูแลระบบ |
| สำเนาสำรองรายวัน (`backups`) | 35 วัน (อัตโนมัติ) + ถังขยะ 30 วัน | อัตโนมัติ | ผู้ดูแลระบบ |
| สำเนาสำรองรายเดือนนอกระบบ | [12] เดือน | ลบไฟล์เข้ารหัส | ผู้ดูแลระบบ |

## การทบทวน

ทบทวนทุก [ไตรมาส]: ตรวจรายการที่ครบกำหนด ลบตามตาราง แล้วบันทึกวันที่ ผู้ลบ และจำนวนรายการในทะเบียนการทำลายข้อมูล ถ้ามีคดีความ การร้องเรียน หรือการตรวจสอบที่ยังไม่จบ ให้ระงับการลบข้อมูลที่เกี่ยวข้องไว้ก่อน
