# นโยบายบัญชีผู้ใช้ อุปกรณ์ และกุญแจ

หน่วยงานไม่มี Google Workspace ระบบจึงจัดการบัญชีผู้ใช้เอง (รหัสผ่านใน Sheets + TOTP ใน Cloudflare D1) เอกสารนี้แทน gate "Identity" และ "Device" ใน `PILOT_RUNBOOK.md`

## 1. บัญชีเจ้าของระบบ (สำคัญที่สุด)

| ระบบ | เจ้าของ | ข้อกำหนด |
|---|---|---|
| บัญชี Google ที่เป็นเจ้าของไฟล์ Sheets, โฟลเดอร์ Drive และโครงการ Apps Script | บัญชีของหน่วยงาน เช่น `ltc.<รพ.สต.>@gmail.com` **ไม่ใช่บัญชีส่วนตัวของเจ้าหน้าที่** | เปิด 2-Step Verification ด้วย passkey/security key หรือแอป Authenticator · ผู้อำนวยการเก็บรหัสกู้คืนและ backup codes ในซองปิดผนึก/ตู้นิรภัย · ทบทวนอุปกรณ์ที่ลงชื่อเข้าใช้ทุกเดือน |
| บัญชี Cloudflare (Worker, D1, KV) | บัญชีของหน่วยงาน (อีเมลเดียวกันได้) | เปิด 2FA · เพิ่มสมาชิกเท่าที่จำเป็น |
| GitHub repository | บัญชีผู้พัฒนาที่หน่วยงานมอบหมาย | เปิด 2FA · branch `main` deploy อัตโนมัติ จึงจำกัดคนที่ push ได้ |

ห้ามแชร์ไฟล์ Sheets หรือโฟลเดอร์กับบุคคลอื่น ผู้ใช้ทุกคนเข้าผ่านหน้าเว็บเท่านั้น ยกเว้นผู้ดูแลระบบสำรองหนึ่งคน (สิทธิ์ Editor) เพื่อรับมือเหตุฉุกเฉิน

## 2. บัญชีผู้ใช้ในระบบ

- **สร้าง:** CM สร้างบัญชี CG ในระบบ; CM สร้างโดยผู้ดูแลระบบผ่าน `createPilotCaseManager` หลังตรวจเอกสาร Care Manager ตัวจริง; ADMIN สร้างโดยเจ้าของระบบผ่าน `createPilotAdmin`
- **ชื่อผู้ใช้:** หนึ่งคนหนึ่งบัญชี ห้ามใช้บัญชีร่วม
- **รหัสผ่าน:** อย่างน้อย 12 ตัวอักษร รหัสชั่วคราวแจ้งต่อหน้าหรือทางโทรศัพท์ ห้ามส่งในกลุ่ม LINE
- **ยืนยันตัวตนสองชั้น:** ทุกบทบาทต้องผูกแอป Authenticator ในโทรศัพท์ของตนเองตอนเข้าสู่ระบบครั้งแรก ผู้ใช้ควรผูกเองทันทีหลังได้รับรหัสชั่วคราว เพราะผู้ที่รู้รหัสผ่านก่อนจะผูกได้ก่อน
- **เปลี่ยนตำแหน่ง/ย้ายพื้นที่:** CM ปรับการมอบหมายผู้รับบริการในวันเดียวกัน
- **พ้นหน้าที่:** ปิดใช้งานบัญชีในวันสุดท้ายของการทำงาน (CG: หน้าแก้ไขผู้ดูแล → ปิดใช้งาน; CM: ตั้ง `enabled=false` ในชีต `Users`) แล้วกด "รีเซ็ตแอปยืนยันตัวตน" เพื่อตัด session ที่ค้างอยู่
- **ทบทวน:** ทุกเดือน CM lead ตรวจหน้า "ข้อมูลผู้ใช้งาน" ว่าไม่มีบัญชีของคนที่ไม่ได้ทำงานแล้ว และใบประกาศนียบัตร CM ยังไม่หมดอายุ

## 3. อุปกรณ์

- ใช้โทรศัพท์/คอมพิวเตอร์ที่ตั้งรหัสล็อกหน้าจอ และอัปเดตระบบปฏิบัติการ
- ไม่บันทึกรหัสผ่านในเบราว์เซอร์ของเครื่องที่ใช้ร่วมกัน และออกจากระบบทุกครั้งบนเครื่องส่วนกลาง
- ห้ามถ่ายภาพหน้าจอข้อมูลผู้รับบริการ ห้ามส่งข้อมูลหรือภาพผู้รับบริการทาง LINE ส่วนตัว
- โทรศัพท์หาย: แจ้ง CM ทันทีให้รีเซ็ตแอปยืนยันตัวตนและตั้งรหัสผ่านใหม่ แล้วรายงานตาม `INCIDENT_RESPONSE.md`

## 4. กุญแจและความลับ

| กุญแจ | อยู่ที่ | ถ้าหาย | ถ้ารั่ว |
|---|---|---|---|
| `CID_ENCRYPTION_KEY_BASE64` | Worker secret + ที่เก็บเข้ารหัส | **อ่านเลขบัตรประชาชนที่บันทึกไว้ไม่ได้อีก** | เป็นเหตุละเมิด ต้องหมุนกุญแจและเข้ารหัสใหม่ |
| `CID_LOOKUP_SECRET` | Worker secret + ที่เก็บเข้ารหัส | ตรวจเลขบัตรซ้ำไม่ได้ | หมุนและคำนวณ hash ใหม่ |
| `MFA_ENCRYPTION_KEY_BASE64` | Worker secret + ที่เก็บเข้ารหัส | ทุกคนต้องผูกแอปใหม่ | หมุน + `pilot-reset.sql` |
| `GATEWAY_ASSERTION_SECRET` | Worker secret + Script Property | สร้างใหม่ได้ | หมุนทั้งสองฝั่งทันที |
| `PASSWORD_PEPPER` | Script Property + ที่เก็บเข้ารหัส | ทุกคนต้องตั้งรหัสผ่านใหม่ | หมุนแล้วตั้งรหัสผ่านใหม่ทุกคน |

- ห้ามเก็บกุญแจใน repository, LINE, อีเมล หรือไฟล์ที่ไม่เข้ารหัส
- ผู้ที่เปิดที่เก็บกุญแจได้: ผู้อำนวยการและผู้ดูแลระบบหนึ่งคน
- บันทึกวันที่สร้าง/หมุนกุญแจ และทบทวนทุก [12] เดือน
